# Cos'è GitHub (in parole semplici)

Sei arrivato qui e ti chiedi "dove sono finito?". Niente panico: questa è una pagina di GitHub, e qui ti spiego cos'è, senza tecnicismi.

## Cos'è GitHub

GitHub è un sito dove si conservano e si condividono file e progetti. È nato per i programmatori, ma si usa per tante cose.

Pensalo come un **Google Drive pensato per i progetti**, con due cose in più: tiene la **storia di ogni modifica** (chi ha cambiato cosa e quando) e permette a più persone di lavorare sugli stessi file senza pestarsi i piedi.

Per te, oggi, GitHub è semplicemente **il posto da cui scarichi il materiale del corso**. Niente di più.

## Perché lo usiamo nel corso

Due motivi:

- **È comodo per consegnarti i file**: un link solo, sempre aggiornato, da cui prendi tutto.
- **Lo incontrerai usando Claude Code**: tante skill già pronte si scaricano proprio da GitHub. Vederlo adesso ti torna utile più avanti.

## Glossario - le parole che vedi in giro

- **Repository** (o "repo"): la cartella-progetto. Questa pagina che stai guardando è un repository.
- **README**: la pagina di benvenuto, quella che si apre da sola quando entri in un repo (l'hai già vista aprendo questo).
- **Code** (il pulsante verde in alto): il pulsante da cui scarichi. Lì dentro trovi "Download ZIP" e il link da copiare.
- **Download ZIP**: scarica tutto come un'unica cartella compressa. Nessuno strumento, solo il browser.
- **Clone** (clonare): scaricare l'intero repo sul tuo computer. È quello che fa Claude quando gli dai il link e gli chiedi di scaricare la cartella: clona lui al posto tuo.
- **Commit**: una modifica salvata, con data e una breve descrizione. La storia di un progetto è una fila di commit.
- **Branch** (ramo): una versione del progetto. Quella principale si chiama quasi sempre "main". Per ora non ti serve.
- **Issue** e **Pull request**: strumenti con cui gli sviluppatori segnalano problemi e propongono modifiche. Non ti servono per il corso; se li vedi, ora sai cosa sono.
- **Star** (la stellina in alto): un "mi piace" / segnalibro per ritrovare un repo più tardi.

## Come scarichi il materiale di questa lezione

Due strade (le trovi anche nel README, la pagina principale):

1. **Download ZIP** - premi il pulsante verde **Code** in alto a destra, poi **Download ZIP**. Trovi la cartella nei tuoi Download.
2. **Chiedilo a Claude** - dai a Claude Code il link del repo e digli *"scarica questa cartella"*. Lo fa lui per te.

Per **leggere** i documenti non devi installare niente: si aprono già formattati qui sul sito, basta cliccarci sopra.
