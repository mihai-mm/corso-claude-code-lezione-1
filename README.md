# Corso Claude Code - Lezione 1

Benvenuto. Qui trovi tutto il materiale della prima lezione: i tuoi primi due collaboratori AI - il **Commerciale** e l'**Account Manager** - e la tua **voce di scrittura**.

Il materiale è di due tipi, in due cartelle. Uno si legge, l'altro si dà a Claude.

> **Non sai cos'è GitHub o ti senti spaesato?** Apri prima il file **Guida a GitHub** (lo trovi nell'elenco qui sopra): te lo spiego in parole semplici, in due minuti.

## Da leggere

Documenti da leggere con calma, quando vuoi. Li puoi leggere direttamente qui sul sito (sono già formattati) oppure scaricarli.

- **Il tuo Commerciale** - dalla call alla proposta pronta da inviare: cos'è una skill, le 6 sezioni della proposta, scrivere col tuo tono.
- **Il tuo Account Manager** - ogni cliente diventa una cartella che ricorda tutto: le memorie del collaboratore e la skill `/recap-call`.
- **Anatomia di una skill** - di cosa è fatta una skill e i tre modi per costruirtene una.

## Da usare con Claude

Questi file **non** devi leggerli tu: li dai a Claude Code e lui fa il lavoro per te. Dentro ognuno c'è scritto come usarlo.

- **Crea il tuo stile di scrittura** - una guida che Claude segue per costruire il tuo `STYLE.md`, partendo dai testi che hai già scritto.
- **Crea la tua skill recap-call** - una guida che Claude segue per costruire con te la skill `/recap-call`.
- **Trascrizione di esempio - Serramenti Furlan** - una call commerciale finta ma realistica, da usare come banco di prova se non hai ancora una tua call registrata.

## Come scaricare il materiale

Due strade, scegli la tua.

### 1. Scarica tutto (semplice)

Premi il pulsante verde **Code** qui in alto a destra, poi **Download ZIP**. Trovi la cartella nei tuoi Download: aprila e hai tutto.

### 2. Chiedilo a Claude (il modo pro)

Apri Claude Code e digli:

> scarica questa cartella: https://github.com/mihai-mm/corso-claude-code-lezione-1

Claude la scarica per te, già pronta nella cartella dove stai lavorando. Non devi sapere nessun comando: lo fa il tuo collaboratore. (Serve che `git` sia installato sul computer; se manca, Claude se ne accorge e ti guida a installarlo.)

## Come si usano i file "Da usare con Claude"

Il meccanismo è sempre lo stesso, ed è la cosa più comoda di tutte:

1. Salva il file nella cartella dove stai lavorando con Claude Code.
2. Apri Claude Code in quella cartella e digli, per esempio:

   > leggi il file "Crea il tuo stile di scrittura.md" e seguilo

3. Da lì in poi è Claude a guidarti, un passo alla volta. Quando vuoi fermarti, basta dire "ci fermiamo qui".

Non devi sapere niente di tecnico: questi file sono istruzioni che Claude legge e segue al posto tuo.
